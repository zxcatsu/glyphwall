# GlyphWall

**Живые обои для Windows 10 и 11: любое видео превращается в цветную мозаику из символов.**

[![Windows](https://img.shields.io/badge/Windows-10%20%2F%2011%20x64-0078D6?logo=windows&logoColor=white)](#системные-требования)
[![Python](https://img.shields.io/badge/Python-3.14-3776AB?logo=python&logoColor=white)](requirements.txt)
[![License](https://img.shields.io/badge/license-MIT-4fd1c5)](LICENSE)

Символы не просто лежат картинкой — они берут цвет из видео, мерцают и живут
за иконками рабочего стола. Процессор при этом почти отдыхает: кадр уходит на
видеокарту в нативном YUV, а яркость ячейки, цвет и выбор символа считает шейдер.

---

## Что умеет

- **Видео любого формата** — MP4, MKV, MOV, WEBM, AVI, даже GIF. Всё, что читает FFmpeg.
- **Четыре набора символов**: классический ASCII, бинарный `01`, буквы из твоего
  файла с кодом (частотный анализ — на экране окажутся символы, которые реально
  встречаются в исходнике), или любые свои.
- **Пять цветовых режимов**: цвета видео, зелёная «матрица», белый, янтарный, циан.
- **Живое превью прямо в настройках** — тянешь мышью, двигаешь, колесо масштабирует.
  То, что видишь в окне, и есть то, что окажется на рабочем столе: шейдер и превью
  считают по одной и той же матрице.
- **Посадка за иконки** — окно встаёт вплотную под ярлыки и сторожит позицию.
  Explorer любит переставлять окна при смене обоев; сторож возвращает всё на место
  за четверть секунды.
- **Экономия** — пауза в полноэкранных играх, ограничение 15 FPS от батареи,
  приоритет процесса ниже обычного.
- **Экспорт в MP4** — если хочется не живых обоев, а готового файла с эффектом.
- **Автозапуск** — галочка в окне, и обои включаются при входе в Windows.

## Установка

Скачай **`GlyphWall-Setup.exe`** со страницы [Releases](../../releases/latest)
и запусти. Права администратора не нужны — программа ставится в профиль
пользователя.

Установщик создаст ярлык в меню «Пуск», добавит запись в «Удаление программ»
и предложит автозапуск.

**Портативная версия:** распакуй `GlyphWall-portable.zip` куда угодно и запусти
`GlyphWall.exe`.

## Как пользоваться

1. Открыть GlyphWall.
2. Выбрать видео.
3. Настроить вид — размер символа, набор, цвет. Превью справа обновляется на лету.
4. Нажать **«Поставить обои»**.

Настройки сохраняются сами. «Снять» возвращает обычные обои.

## Системные требования

| | |
|---|---|
| **ОС** | Windows 10 (1809 и новее) или Windows 11, **только x64** |
| **Видеокарта** | любая с OpenGL 3.3 — всё, что выпущено после ~2010, включая встроенную Intel HD 4000 |
| **Оперативная память** | 200 МБ в работе, кэш видео на диске — примерно как исходник в 720p |
| **Права** | обычный пользователь, администратор не нужен |

32-битные системы и Windows 7/8 не поддерживаются: программа собрана под x64
и использует API, которых в старых версиях нет.

## Как это работает

Коротко: **один раз пережать, дальше только GPU.**

```
видео ──► прокси-кэш 720p ──► декодер PyAV ──► плоскости YUV ──► текстура GL
                                                                      │
                          шейдер GRID_FRAG: YUV→RGB, средняя яркость ячейки
                                                                      │
                          шейдер GLYPH_FRAG: выбор символа из атласа по яркости
                                                                      │
                          шейдер BLIT: вывод на экран с апскейлом
```

Несколько решений, которые дали основную экономию:

**Прокси-кэш.** Исходник один раз пережимается в 720p H.264 и лежит в
`%LOCALAPPDATA%\GlyphWall\proxy\`. Дальше декодируется лёгкий файл вместо
4K-исходника. Это дало падение с 58 % до 8 % ядра — в семь раз.

**Без конвертации в RGB.** `VideoSource` отдаёт нативные плоскости YUV прямо
из декодера. Конвертация в RGB на процессоре — самая дорогая часть наивной
реализации; здесь её делает шейдер, попутно усредняя яркость по площади ячейки.

**Аппаратный декодер не пригодился.** Пробовали — выбросили. Кадр всё равно
приходится спускать из видеопамяти в обычную, чтобы отдать в текстуру OpenGL,
и эта копия выходит дороже самого декодирования.

**Усреднение через мипмапы.** `textureGrad` с подобранным уровнем мипа — GPU сам
считает средний цвет ячейки за один сэмпл. Никаких циклов по пикселям.

**Одна матрица на всё.** `frame_matrix()` возвращает аффинное преобразование,
которое идёт и в шейдер (через обратную), и в превью окна настроек. Поэтому
превью совпадает с результатом до пикселя.

## Замеры

Живой процесс, 2560×1440, 10 секунд на вариант:

| режим | CPU | RAM |
|---|---|---|
| прокси 720p | **8.1 %** ядра | 193 МБ |
| исходник 1440p, без прокси | 58.4 % ядра | 294 МБ |
| прокси, рендер в 4K | 7.3 % ядра | 194 МБ |
| прокси, огромные символы (28 px) | 9.2 % ядра | 194 МБ |

## Командная строка

```
--run=gui          окно настроек (по умолчанию)
--run=preview      превью, Esc — выход
--run=wallpaper    посадить за иконки рабочего стола
--run=export       отрендерить видео в MP4 (--out=файл.mp4)
--run=proxy        собрать 720p-кэш (--progress=файл)
--version          показать версию
--check-update     проверить обновления
```

## Обновления

Программа раз в несколько часов смотрит последний релиз на GitHub. Если версия
новее — в окне появляется баннер с описанием изменений. При автозапуске вместо
баннера приходит уведомление Windows, один раз на версию.

## Сборка из исходников

```bash
py -m pip install -r requirements.txt
build_exe.bat          # -> dist\GlyphWall\GlyphWall.exe
build_installer.bat    # -> installer\GlyphWall-Setup.exe
```

`build_installer.bat` требует [Inno Setup 6](https://jrsoftware.org/isinfo.php):
`winget install JRSoftware.InnoSetup`.

Запуск без сборки: `run_dev.bat` или `py glyphwall.py`.

## Настройки и кэш

Всё лежит в профиле пользователя, не рядом с программой:

- `%APPDATA%\GlyphWall\settings.json` — настройки
- `%LOCALAPPDATA%\GlyphWall\proxy\` — прокси-копии видео, по одной на файл

Кэш можно удалять в любой момент — пересоберётся. При удалении программы
деинсталлятор спросит, стирать ли эти папки.
